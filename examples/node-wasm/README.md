# Node WASM Smoke Test

This package loads the Emscripten WASM build.

```sh
npm test --prefix examples/node-wasm
npm run bench --prefix examples/node-wasm
```

The generated package is copied to `examples/node-wasm/pkg/`. It is ignored
by git and regenerated by the npm scripts.
